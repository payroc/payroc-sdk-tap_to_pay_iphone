# Payroc Tap to Pay on iPhone SDK

Accept Apple Tap to Pay on iPhone transactions with the Payroc Tap to Pay on iPhone SDK.

## Overview

The SDK enables card-present payments directly on iPhone using Apple Tap to Pay (ProximityReader). No external hardware is required. It supports Sale and Refund transactions through an Objective-C API that bridges into Swift.

## Getting started

1. Read the integration guide: https://docs.payroc.com/guides/payments/tap-to-pay-on-iphone/set-up-the-sdk
2. Download the latest package (SDK, documentation and sample applications) from the Releases page of this repository.
3. Verify the download against the SHA256SUMS file attached to the release.

Sample applications are provided for reference and testing only, and are not intended for production use.
